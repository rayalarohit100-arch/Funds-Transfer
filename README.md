# Fund Tracker ERP

This package contains the front-end and back-end code for the Google Sheets-based Fund Tracker.

## Instructions for Setup
1. Paste `Code.gs` into your Apps Script. Deploy as Web App -> Execute as Me -> Access: Anyone.
2. Run `npm install` in the React folder.
3. Add the deployed URL to `APPS_SCRIPT_URL` in `src/App.js`.
4. Run `npm start`.
